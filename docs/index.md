# array_manager

This package enables easy, efficient assembly and format conversions for matrices 
assembled from a large number of submatrices that are provided in different formats.
Assemble vectors and block matrices from named components, then convert matrices
to NumPy dense arrays or SciPy COO, CSR, and CSC sparse matrices.
The package depends on NumPy and SciPy.
